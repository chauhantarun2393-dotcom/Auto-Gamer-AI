# Free Fire mobile controls and settings

This guide is for playing Free Fire on a phone or tablet using the game's own touchscreen controls. It does not automate gameplay or modify the game.

## Customize the HUD

Open the game's **Settings → Controls → Custom HUD** (menu labels may vary by version) and arrange the buttons for comfortable reach:

- Keep the movement joystick within easy thumb reach on the lower-left.
- Place fire, aim, jump, crouch, and prone buttons where your right thumb can reach them without covering important screen areas.
- Keep reload, weapon switch, backpack, and interact/pickup controls accessible but separate enough to avoid accidental taps.
- Adjust button size and transparency to balance visibility with screen space.
- Save the layout and test it in training mode before using it in a match.

There is no universally best layout. Hand size, phone dimensions, and whether you use two, three, or four fingers all affect comfort. Change one part of the HUD at a time and keep a screenshot of a layout you like so you can restore it.

## Sensitivity

Sensitivity varies with device size, touch sampling, frame rate, and personal preference. Start with the game's defaults, test in training mode, and make small changes to one setting at a time. If aim feels too jumpy, lower the relevant sensitivity slightly; if turning feels too slow, raise it gradually. Avoid copying values from another device without testing.

## Mobile tips

- Enable the game's supported high-frame-rate or graphics options only if your device runs them reliably.
- Close unnecessary background apps if the game stutters, and keep the device cool.
- Use the in-game accessibility and control options where available.
- Do not use macros, auto-tap tools, modified clients, or third-party gameplay automation; these can create account and device security risks and may violate game rules.
- Menu names and features can change after game updates, so check the current in-game settings if a label differs.
