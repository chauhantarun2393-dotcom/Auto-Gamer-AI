# Free Fire: manual emulator controls setup

This guide helps you configure controls using the emulator's built-in key-mapping editor. It does not automate gameplay or send inputs for you. Emulator versions, platforms, and game updates can change the available controls, so treat the mappings below as a starting point and adjust them in the emulator UI.

## Set up

1. Open Free Fire in your emulator and enter the emulator's control/key-mapping editor.
2. Use the editor to bind keyboard and mouse inputs to the on-screen controls. Prefer the emulator's built-in game profile if one is available.
3. Starting point to customize:
   - Movement: `W`, `A`, `S`, `D`
   - Jump: `Space`
   - Crouch: `C`
   - Prone: `Z`
   - Reload: `R`
   - Interact/pick up: `F`
   - Backpack: `Tab`
   - Map: `M`
   - Fire and aim: assign through the emulator's on-screen mouse controls; avoid binding conflicting buttons.
4. Save the profile, test it in training/practice, and adjust bindings that conflict with chat, menus, or in-game actions.

## Sensitivity tuning

There is no universally best sensitivity; it depends on your mouse DPI, emulator resolution, frame rate, and preference. Start with the game's defaults, change one setting at a time in small increments, and test in training mode. Keep a note of each change so you can revert it. Avoid copying settings intended for a different DPI or resolution without testing.

## Accessibility tips

- Choose keys that are comfortable and reachable for your hands.
- Avoid multi-action macros or automated aim/fire input; use only direct controls supported by the game and emulator.
- If you use an accessibility device, configure it through the operating system or emulator's supported accessibility settings.

## Troubleshooting

- If a key does nothing, check that the emulator control overlay is enabled and that the game has focus.
- If a key triggers the wrong action, remove duplicate bindings in the emulator editor.
- If controls shift after an update or resolution change, reopen the editor and recalibrate the on-screen control positions.
